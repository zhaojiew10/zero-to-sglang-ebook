# 第一部分 · 推理基础

本部分不急于修改引擎，而是建立后续所有章节共用的模型：LLM 如何生成、Prefill 与 Decode 有何不同、GPU 为什么出现瓶颈、KV Cache 如何权衡计算与显存，以及 Benchmark 如何给出可信证据。

| 章节 | 学习闭环 | 对应视频 |
|---|---|---|
| 第 1 章 | LLM、Transformer、自回归生成 | 第 01 讲 |
| 第 2 章 | 训练与推理、Compute/Memory-Bound、Roofline | 第 02 讲 |
| 第 3 章 | GPU 执行与存储层次、推理瓶颈 | 第 03 讲 |
| 第 4 章 | KV Cache 的推导、生命周期和显存估算 | 第 04 讲 |
| 第 5 章 | TTFT/TPOT/ITL/Goodput、尾延迟和实验设计 | 第 05 讲 |

完成本部分后，应能用统一指标描述一个推理负载，而不是只说“速度快”或“显存不够”。
